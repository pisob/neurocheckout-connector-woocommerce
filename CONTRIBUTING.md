# Contributions

Le code est public, mais les contributions externes sont temporairement fermées.
Il est possible de proposer une amélioration dans une issue, sans données privées.
Une pull request n'est jamais une autorisation de fusion ni de publication.

Pour les mainteneurs : toute modification passe par une pull request, des tests
réussis et une revue humaine. Aucun merge automatique, force-push ou effacement
de la branche principale. Les changements de signature, permissions, chiffrement,
quotas, endpoints et workflows demandent une revue de sécurité particulière.

Ne pas lancer de code externe avec des secrets ni sur un runner auto-hébergé.
Les workflows de forks doivent être approuvés manuellement avant exécution.
Ne pas copier de code sans licence compatible ni supprimer les notices tierces.
Les contributions acceptées seront distribuées sous la licence du dépôt.

Les protections exigeant une approbation nécessitent un autre mainteneur habilité
pour fusionner une PR écrite par le propriétaire. Ne pas contourner cette règle.
