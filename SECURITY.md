# Security

Signaler confidentiellement une vulnérabilité à **contact@neurocheckout.com**,
objet « Security — WooCommerce connector », ou utiliser le signalement privé GitHub
s'il est activé. Ne pas ouvrir d'issue publique contenant un exploit, une clé,
des données clients ou l'adresse privée d'une boutique.

Ces sources sont en développement et n'ont pas fait l'objet d'un audit externe.
Les tests automatisés et revues internes ne garantissent pas l'absence de failles.
Aucune plage de versions de production nouvellement certifiée n'est annoncée.

N'installez que des paquets officiels dont signature et checksum ont été vérifiés,
lorsqu'ils sont disponibles. Un checksum seul ne prouve pas l'origine.
Une signature ne garantit pas l'absence de bugs.
